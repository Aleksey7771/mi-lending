# Идея: AI-агент для оптовика рыбопродукцией

> Дата: 11 ноября 2026  
> Автор: владелец бизнеса (опрос + формализация)

---

## Контекст бизнеса

Оптовая торговля свежемороженной рыбой и морепродуктами с Дальнего Востока России (Сахалин, Камчатка, Приморский и Хабаровский край). Владелец работает один — совмещает роли закупщика, коммерческого директора и маркетолога.

---

## Проблема

Владелец ежедневно тратит несколько часов на рутину:
- Мониторинг цен: открывает прайсы, сверяет позиции вручную
- Обзвон поставщиков и конкурентов для уточнения актуальных цен
- Рассылка своего прайса по Telegram-группам, WhatsApp-группам, email
- Публикация постов и фотографий в соцсетях (Telegram-канал, ВКонтакте, Одноклассники/OK)
- Составление и оформление коммерческих предложений (PDF с логотипом)

## 3а. УНИВЕРСАЛЬНЫЙ КОННЕКТОР ИСТОЧНИКОВ

**Идея:** владелец вставляет любую ссылку в бота, и агент автоматически начинает мониторить этот источник.

```
Пользователь → Бот: [вставляет ссылку]
Бот: «Добавил источник. Тип: Telegram-канал.
     Уже нашёл 3 позиции с ценами. Мониторить?»
Пользователь: «Да»
Бот: «Добавлен в список мониторинга. Буду проверять каждые 2 часа.»
```

| Тип ссылки | Как обрабатывается | Что извлекает |
|---|---|---|
| Сайт (fishnet.ru, fishretail.ru и др.) | HTML-парсер + LLM-экстракция | Позиции, цены, даты |
| Telegram-канал/группа (t.me/...) | Telegram User API (Telethon) | Сообщения с ценами, прайс-файлы |
| ВКонтакте (vk.com/...) | VK API | Посты с ценами, прикреплённые файлы |
| MAX (max.ru/...) | Web-парсер или API | Объявления, цены |
| PDF/Excel файл (прямая ссылка) | Скачивает + парсит файл | Таблица позиций |
| Любой другой сайт | LLM читает HTML → извлекает данные | Всё, что похоже на цены |

**Алгоритм обработки новой ссылки:**
1. Бот определяет тип источника (сайт / Telegram / VK / файл)
2. Пробует извлечь данные о ценах через LLM
3. Показывает владельцу что нашёл: «Вижу треску 185₽, минтай 95₽. Верно?»
4. Владелец подтверждает → источник добавляется в регулярный мониторинг
5. При изменении цен — уведомление в бот

**Почему это важно:** рынок постоянно меняется — появляются новые поставщики, каналы, сайты. Владелец не должен просить разработчика добавить новый источник — он делает это сам за 10 секунд.

## 3б. ИСТОЧНИКИ КЛИЕНТСКОЙ БАЗЫ (потенциальные покупатели)

Парсинг **2ГИС по Владивостоку** для сбора контактов потенциальных покупателей рыбопродукции.

| Категория в 2ГИС | Кто это | Зачем нам |
|---|---|---|
| Рестораны, кафе, суши-бары | HoReCa | Регулярные оптовые закупки рыбы |
| Столовые, корпоративное питание | HoReCa | Крупные объёмы, стабильные заказы |
| Рыбные магазины, рыбные отделы | Розничная торговля | Прямые перекупщики |
| Коптильни, рыбоперерабатывающие цеха | Переработчики | Крупные партии сырья |
| Пивные магазины, снэк-производства | Переработчики | Вяленая/сушёная рыба |
| Гостиницы, санатории | HoReCa | Постоянные поставки |
| Супермаркеты, продуктовые сети | Ретейл | Крупные закупки |

**Что собираем из 2ГИС:**
- Название организации
- Адрес
- Телефон
- Категория бизнеса
- Ссылка на профиль (для верификации)

**Статус парсинга 2ГИС:** ⚠️ Полуавтоматически — официального API нет, но данные доступны через веб-версию (2gis.ru). Инструменты: Selenium / Playwright или готовые парсеры (2gis-parser на GitHub).

**Результат:** структурированная база потенциальных клиентов → загружается в бота → владелец делает первичный обзвон / рассылку КП.
