# @lexavlbot — CLAUDE.md

Персональный AI-ассистент владельца оптовой торговли морепродуктами (Дальний Восток).
Принимает команды в Telegram, генерирует посты/КП/прайсы через DeepSeek V3, публикует
в Max и Telegram-канал после одобрения пользователя. Один владелец, работает 24/7 на VPS.

## 5 ключевых решений

| Решение | Почему |
|---------|--------|
| **Цены только из SQLite** | AI не называет цену из головы — исключает ошибки и галлюцинации |
| **Два Max-бота** | Контентный бот и диалоговый бот — разные роли, разные права |
| **Владелец всегда одобряет** | Никакой автопубликации — исключает репутационные риски |
| **DeepSeek V3 для текста** | Лучший русский в нише + ~$0.001/пост (в 100x дешевле GPT-4o) |
| **Style feedback loop** | Нет примеров стиля на старте → накапливаем оценки → улучшаем промпт |

## Тестирование

**Где тесты:** `../tests/` (пока пусто — создавать по мере разработки)

**Как тестировать вручную (чек-лист перед релизом):**
- [ ] /start отвечает только владельцу (ALLOWED_USER_ID), чужие игнорируются
- [ ] "напиши пост про горбушу" → берёт цену из каталога, не придумывает
- [ ] AI не называет цену для товара с `in_stock=false`
- [ ] AI не раскрывает `price_vip` публично
- [ ] Прайс-подтверждение: правка одной позиции обновляет каталог
- [ ] PDF КП содержит логотип и актуальные цены
- [ ] Ошибка OpenRouter → уведомление владельцу, бот не падает
- [ ] Незнакомый вопрос клиента → "уточню у менеджера" + уведомление владельцу

**Юнит-тесты (написать):** `tests/test_router.py` — проверка 10 намерений
**Интеграционные:** запуск с реальным `.env.test`, проверка публикации в тест-канал

## Commands

```bash
# Локальный запуск
cd tg-bot
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python main.py

# Деплой на VPS
scp -r tg-bot/ user@server:/opt/lexavlbot/
ssh user@server
cd /opt/lexavlbot
pip install -r requirements.txt
# Запуск через systemd или screen:
screen -S lexavlbot python main.py

# Перезапуск после обновления
screen -r lexavlbot   # Ctrl+C → python main.py

# Проверка логов
tail -f /opt/lexavlbot/bot.log
```

## Самообновление

| Файл | За что отвечает | Как обновляется |
|------|----------------|----------------|
| `db/models.py` | Схема БД — единственный источник правды по структуре | При изменении полей → `ALTER TABLE` или миграция |
| `ai/prompts/*.py` | Промпты всех AI-задач | При изменении стиля или правил генерации |
| `db/style.py:style_profile` | Текущий стиль пользователя | Автоматически: каждые 10 оценок пересчитывается |
| `settings` (таблица БД) | Доставка, реквизиты, менеджер-контакт | Через команду `/settings` или прямо в SQLite |
| `.env` | Токены и модели | Вручную, перезапуск после изменения |
| `CLAUDE.md` (этот файл) | Ориентация Claude в новой сессии | При добавлении модулей или смене стека |

**Правило:** если меняешь промпт → обнови `ai/prompts/`. Если меняешь БД → обнови `db/models.py` и `CLAUDE.md`. Если меняешь бизнес-логику → обнови спецификацию.
