# OCR Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local OCR script that extracts text from PDFs and images cheaply, plus a Claude Code slash command to call it from chat.

**Architecture:** A single Python CLI script handles both PDFs (via pymupdf) and images (via pytesseract). It prints extracted text to stdout and copies it to the clipboard. A Claude Code slash command wraps the script so it can be called with `/ocr <path>` from VSCode chat.

**Tech Stack:** Python 3, pymupdf, pytesseract, pyperclip, Tesseract OCR (system dependency)

**Spec:** Approved in conversation — brainstorming session 2026-11-26

## Global Constraints

- Python 3.8+ required
- Windows 10 (primary platform)
- Tesseract must be installed at default path `C:\Program Files\Tesseract-OCR\tesseract.exe`
- Script lives at `tools/ocr/ocr.py`
- Slash command lives at `.claude/commands/ocr.md`
- No external API calls — fully local, zero cost

## Review Focus

- Image with no readable text (blank screenshot, photo of a blank wall) — should return empty string with a warning, not crash
- PDF with only scanned images (no text layer) — pymupdf returns empty; script should warn "PDF has no text layer, try treating as image"
- Path with spaces (e.g. `C:\Users\User\Documents\my scan.pdf`) — must be quoted; script should handle unquoted multi-word paths gracefully with a clear error
- Tesseract not installed — should give a human-readable error pointing to the install instructions, not a Python traceback
- Unsupported file extension (.docx, .xlsx) — should list supported formats and exit cleanly

import fitz  # pymupdf

def extract_pdf(path: str) -> str:
    if not os.path.exists(path):
        raise FileNotFoundError(f"File not found: {path}")
    doc = fitz.open(path)
    pages = [page.get_text() for page in doc]
    text = "\n\n".join(pages).strip()
    if not text:
        print("[WARNING] PDF has no text layer. Try scanning the PDF as an image.", file=sys.stderr)
    return text
```

import pytesseract
from PIL import Image

TESSERACT_PATH = r"C:\Program Files\Tesseract-OCR\tesseract.exe"

def extract_image(path: str) -> str:
    if not os.path.exists(path):
        raise FileNotFoundError(f"File not found: {path}")
    try:
        pytesseract.pytesseract.tesseract_cmd = TESSERACT_PATH
        img = Image.open(path)
        text = pytesseract.image_to_string(img, lang="rus+eng").strip()
    except pytesseract.TesseractNotFoundError:
        print("[ERROR] Tesseract not installed. See tools/ocr/INSTALL.md", file=sys.stderr)
        sys.exit(1)
    if not text:
        print("[WARNING] No text detected in image.", file=sys.stderr)
    return text
```
