# @lexavlbot — AI-ассистент для продвижения товаров

**Дата:** 2026-11-27  
**Статус:** На согласовании

---

## Идея и зачем

Владелец оптового бизнеса (рыба) тратит время на рутину: сделать пост, написать КП, дать объявление. Задача бота — взять эту рутину на себя. Пользователь кидает фото + голосовую/текстовую команду в Telegram, бот генерирует готовый контент, показывает превью, и по нажатию одной кнопки публикует в нужное место.

**Почему важно:** одно объявление на трёх площадках вручную = 20–30 минут. С ботом — 2 минуты.

---

## Цели

- Принять фото + команду от пользователя в Telegram
- Сгенерировать текст нужного формата (пост, объявление, КП) через AI
- Показать превью перед публикацией
- Опубликовать в Max одним нажатием
- Хранить каталог товаров (название, цена, описание, фото) чтобы не повторять данные каждый раз

## Не-цели (v1)

- Авито, Фарпост, WhatsApp — следующая версия
- Аналитика / статистика публикаций
- Автоматическая публикация без подтверждения пользователя
- Мультипользовательский режим

## Анти-цели (что сделает проект провальным)

- Бот публикует без подтверждения — риск ошибки
- Слишком сложный ввод команд (пользователь должен помнить синтаксис)
- Медленная генерация (>10 сек ожидания без индикатора)

## Как устроено (архитектура)

### Компоненты

```
[Пользователь в Telegram]
        ↓ фото + команда
[@lexavlbot — Telegram Bot]
        ↓
[Роутер команд]
    ├── "добавь товар" → [Каталог товаров (SQLite)]
    ├── "напиши пост/объявление/КП" → [AI генерация (DeepSeek V3 via OpenRouter)]
    │                                        ↓ текст
    │                               [Превью пользователю]
    │                                        ↓ кнопка "Опубликовать"
    └── публикация → [Max Bot API]
```

### Технический стек

- **Язык:** Python (уже используется в проекте)
- **Telegram:** aiogram 3.x
- **AI:** OpenRouter API → DeepSeek V3 (тексты/посты), Claude Haiku 5.5 (диалог с клиентами)
- **Хранилище:** SQLite — каталог товаров
- **Max:** Max Bot API (REST) — публикация постов
- **Фото:** хранятся как Telegram file_id + путь; для генерации описания — vision-модель (Haiku)

### Структура каталога товаров

```sql
CREATE TABLE products (
    id INTEGER PRIMARY KEY,
    name TEXT,           -- "Горбуша"
    unit TEXT,           -- "кг", "блок", "ящик"
    price_wholesale REAL,
    price_retail REAL,
    description TEXT,    -- краткое описание
    photo_file_id TEXT,  -- Telegram file_id последнего фото
    created_at DATETIME
);
```

## Основные сценарии использования

### Сценарий 1 — Пост с фото
1. Пользователь: отправляет фото + "напиши пост про горбушу в Max"
2. Бот: находит "горбуша" в каталоге, берёт цену и описание
3. Бот: генерирует пост через DeepSeek V3
4. Бот: показывает превью + кнопки [Опубликовать] [Переписать] [Отмена]
5. Пользователь: нажимает [Опубликовать]
6. Бот: постит в Max, сообщает "✓ Опубликовано"

### Сценарий 2 — Добавить товар в каталог
1. Пользователь: "добавь товар: горбуша, 1 кг, 450₽ опт, 580₽ розница"
2. Бот: парсит данные, сохраняет
3. Бот: "Горбуша добавлена. Прислать фото?"
4. Пользователь: присылает фото → сохраняется к товару

### Сценарий 3 — КП без фото
1. Пользователь: "сделай КП на минтай блочный для ресторана"
2. Бот: берёт данные из каталога
3. Бот: генерирует КП в формате текста
4. Бот: превью + [Отправить в Max] [Скопировать] [Переписать]

### Сценарий 4 — Отправка прайса с проверкой цен
1. Пользователь: "отправь прайс в Max"
2. Бот: формирует прайс из каталога, показывает таблицу цен
3. Бот: спрашивает "Цены актуальны? Отправляем?"
4. Пользователь: "да" → бот публикует прайс в Max
5. Пользователь: "нет, горбушу на 480" → бот исправляет позицию в каталоге, показывает обновлённый прайс → шаг 3 повторяется

### Сценарий 5 — Ответ клиенту
1. Клиент пишет боту в Max: "есть горбуша? сколько стоит?"
2. Бот: отвечает через Haiku 5.5, используя данные каталога
3. Пользователь получает уведомление в Telegram о диалоге

## Формат команд (NLU, не синтаксис)

Пользователь пишет свободным текстом. Роутер на базе AI определяет намерение:
- "напиши пост / объявление / КП" → генерация контента
- "добавь товар / обнови цену" → работа с каталогом
- "покажи каталог" → список товаров
- "разошли в Max" → публикация последнего контента

## Решения по открытым вопросам

| Вопрос | Решение | Кто решил |
|--------|---------|-----------|
| Два Max-бота или один? | Два: `@lexav_post_bot` постит контент, `@lexav_chat_bot` принимает клиентов | Пользователь |
| КП — текст или PDF? | PDF-файл, используется `fish-agent/pdf/generator.py` | Пользователь |
| AI получает данные каталога? | Да, всегда — иначе каталог бессмысленен | Разработчик |
| Безопасность (кто может писать боту)? | ALLOWED_USER_ID в `.env`, остальные молча игнорируются | Разработчик |
| Голосовые команды? | v1 — только текст; STT в v2 | Разработчик |
| Кнопка "Переписать" | Генерирует заново с тем же промптом | Разработчик |
