# Исследование: AI-боты в оптовой торговле рыбой и продуктами питания

> Дата: 11 ноября 2026  
> Цель: найти 5–7 успешных AI/автоматизированных ботов в нише оптовой торговли рыбой, мясом и продуктами питания — для доработки технической спецификации.  
> Метод: 4 параллельных агента с разными фокусами исследования (рыбная ниша / мониторинг цен / рассылки+PDF / контент соцсетей).

## Ключевой вывод

**Специализированных ботов «всё в одном» для рыбного оптовика не существует.** Единственный прямой конкурент в нише — Fishplace (@fishplacesales, октябрь 2025, тестовый режим). Рынок незрелый. Решение строится из проверенных паттернов смежных ниш.

## Пример 1 — Fishplace (@fishplacesales)

**Платформа:** Telegram-канал + бот  
**Страна:** Россия  
**Статус:** Тестовый запуск, октябрь 2025  
**Источник:** [press-release.ru](https://www.press-release.ru/branches/hitech/_telegram__27_10_2025_08_32/)

### Задача
Уведомление покупателей рыбы о новых партиях, выставленных поставщиками на платформе Fishplace (280+ рыбных компаний, 110+ складов).

### Функции
- Автопубликация карточки партии после размещения поставщиком
- Пуш-уведомление подписчикам в реальном времени
- Хэштеги по виду рыбы (#лосось #треска #дальнийвосток)
- Экспортный статус (страны поставки)
- Ссылка на полную карточку товара

### Пример типичного сообщения
```
📦 ГОРБУША б/г 1/22 — 500 кг
💰 185 ₽/кг
🏭 ООО Камчатрыба
🌍 Экспорт: Китай, Япония
#горбуша #лосось #дальнийвосток
👉 Посмотреть детали: [ссылка]
```

### Почему работает
- Покупатель подписывается и получает уведомления вместо мониторинга прайсов вручную
- Скорость: информация о партии поступает сразу после публикации
- Хэштеги заменяют ручной поиск по прайс-листам

### Ограничения
- Только push-уведомления, без диалога и запросов
- Нет сравнения цен между поставщиками
- Нет истории цен и аналитики

### Что взять для нашего бота
- Формат карточки партии (позиция + регион + количество + цена + производитель)
- Хэштег-система для фильтрации по виду рыбы
- Пуш-уведомление клиентам при обновлении прайса или появлении новой партии
- Идея канала-агрегатора предложений как «витрины»

## Пример 2 — Neurobot: бот для оптовой продажи продуктов питания

**Платформа:** Telegram, VK, MAX, сайт  
**Страна:** Россия  
**Тип:** Готовое решение под заказ (no-code + разработка)  
**Источник:** [neurobot.ru/solution/optovaia-prodazha-produktov-pitaniia](https://neurobot.ru/solution/optovaia-prodazha-produktov-pitaniia)

### Задача
Автоматизация приёма оптовых заявок и обработки заказов на продукты питания. Уточняет параметры, проверяет наличие, передаёт заявку менеджеру.

### Функции
- Три варианта реализации: скриптовый бот (кнопки-меню), AI-бот (свободный диалог), Mini App
- Уточнение: категория товара, объём, частота поставок, регион, временны́е окна доставки
- Проверка наличия и предложение аналогов при отсутствии позиции
- Приём заявки файлом (Excel-спецификация) или по позициям кнопками
- Генерация КП и счёта
- Статусные уведомления о заказе
- Приём рекламаций (номер партии + описание проблемы)
- Единая настройка для всех каналов (Telegram, VK, MAX, виджет на сайте)
- Интеграции: 1С, Bitrix24, amoCRM, YooKassa

### Пример диалога
```
Клиент: «Пришлите прайс и условия доставки по рыбе»

Бот: «Уточните категорию (лосось, треска, минтай?)
     и регион доставки»

Клиент: «Лосось, Москва, от 500 кг»

Бот: «Высылаю прайс для Вашего сегмента.
     Минимальная партия — 500 кг, доставка 2 дня.
     Оформить предварительный счёт?»

Клиент: «Да, 700 кг филе и 300 кг стейков»

Бот: «Формирую счёт... Готово.
     Заявка передана менеджеру, свяжется через 2 часа.»
```

### Почему работает
- Единственный найденный сервис с готовым шаблоном для оптовой торговли продуктами
- Охватывает несколько каналов из одной настройки
- Знает специфику опта: весовые позиции, партионность, рекламации, временны́е окна

### Ограничения
- Не охватывает: мониторинг цен поставщиков, рассылку по Telegram-группам/WhatsApp/email
- Нет AI-генерации контента для соцсетей

### Что взять для нашего бота
- Уточнение типа покупателя → выдача сегментных цен (ресторан / магазин / переработчик)
- Приём заявки Excel-файлом — стандарт в рыбной торговле
- Аналоги при отсутствии позиции — важно при сезонных уловах
- Статусные уведомления — снижает нагрузку на звонки владельцу

## Пример 3 — GrubMarket Sales AI Agent

**Платформа:** Web + интеграции (email/SMS/WhatsApp)  
**Страна:** США  
**Источник:** [prnewswire.com](https://www.prnewswire.com/news-releases/grubmarket-announces-sales-ai-agent-that-transforms-prospecting-and-quote-creation-for-food-distributors-302793878.html)

### Задача
AI-агент для продуктовых дистрибьюторов: анализирует меню ресторана или прайс клиента и автоматически генерирует персональный прайс-лист КП. Убирает 2–3 часа ручного составления документов.

### Функции
- Анализ меню ресторана или прайса клиента (PDF / фото)
- Матчинг позиций клиента с каталогом дистрибьютора
- Генерация персонального price sheet
- Менеджер редактирует и отправляет по email/SMS/WhatsApp
- Интеграция с WholesaleWare ERP, Thyme Software и другими системами учёта

### Пример рабочего процесса
```
AI анализирует PDF с меню ресторана
→ Находит все позиции, которые может поставить дистрибьютор
→ Формирует персональный прайс-лист с ценами
→ Менеджер нажимает «Отправить»
```

### Почему работает
- Менеджер за 5 минут делает то, что раньше занимало полдня
- Персонализация КП под конкретного клиента без ручного составления
- Интеграция с ERP исключает расхождения остатков и цен

### Ограничения
- Корпоративное решение, дорогостоящее
- Ориентировано на крупных дистрибьюторов (США), не на одного человека

### Что взять для нашего бота
- Автоматическая генерация PDF с логотипом и актуальными ценами по команде
- Матчинг позиций клиента со своим прайсом по запросу
- Отправка финального КП через Telegram вместо email
- Принцип «AI готовит → человек одобряет → отправляет»

## Пример 4 — B2B-бот оптовика (кейс vc.ru / закрытая система)

**Платформа:** Telegram + Mini App  
**Страна:** Россия  
**Источник:** [vc.ru/dev/2287961](https://vc.ru/dev/2287961-avtomatizatsiya-optovykh-zakazov-cherez-telegram)

### Задача
Закрытый Telegram-бот для региональных оптовых покупателей. Заменяет звонки, Excel по email и мессенджеры одним каналом. Владелец загружает новый прайс — все клиенты получают уведомление автоматически.

### Функции
- Просмотр актуального прайса прямо в боте по команде `/preis`
- Оформление заказа через загрузку Excel-файла или добавление позиций кнопками
- Mini App с историей заказов клиента
- **Менеджерская панель:** загрузка нового прайса → автоматическое уведомление всех клиентов
- Принятие/отклонение заказа в один клик с уведомлением клиента
- Распределение заявок между менеджерами
- Выгрузка в учётную систему

### Пример диалога
```
Клиент: нажимает «Прайс» → получает актуальный PDF
Клиент: нажимает «Новый заказ» → загружает Excel-спецификацию
Бот: «Заявка принята #1247. Менеджер обработает через 2 часа.»

[У менеджера в панели]
Менеджер загружает новый прайс →
Все клиенты получают: «Прайс обновлён, скачайте актуальную версию [PDF]»
```

### Почему работает
- Уведомление всех клиентов при смене прайса — точная аналогия ежедневного обновления цен на рыбу
- Владелец, работающий один, загружает прайс и клиенты узнают сами
- Загрузка заявки Excel-файлом — стандарт в рыбной оптовой торговле
- Время обработки заказа: с нескольких минут до одного клика

### Ограничения
- Только Telegram, нет WhatsApp/email
- Не охватывает мониторинг цен поставщиков, публикацию контента

### Что взять для нашего бота
- Уведомление клиентов при смене прайса — команда приоритет 1
- Менеджерская панель для загрузки нового прайса в два клика
- Команда `/preis` для получения актуального PDF-прайса
- Загрузка заказа Excel + ручное добавление позиций кнопками

## Пример 5 — price-monitoring (open-source) + ai-competitor-watchdog

**Платформа:** Telegram (уведомления) + любые источники прайсов  
**Страна:** Россия (open-source)  
**Источники:**  
- [github.com/Yaroslava-111/price-monitoring](https://github.com/Yaroslava-111/price-monitoring)  
- [github.com/domiczxc1-beep/ai-competitor-watchdog-bot](https://github.com/domiczxc1-beep/ai-competitor-watchdog-bot)

### Задача
Автоматический импорт прайс-листов от поставщиков, нечёткое сопоставление позиций (fuzzy matching), генерация отчёта об отклонениях цен и рекомендация самого выгодного поставщика. Уведомление в Telegram при значительных изменениях.

### Функции (price-monitoring)
- Импорт прайсов из Excel/CSV
- **Fuzzy matching наименований** — сравнивает «Лосось б/г 2–3 кг» и «Лосось без головы 2–3» как одну позицию
- Статистика: мин./макс./средняя цена по каждой позиции за период
- Автоматическая рекомендация самого выгодного поставщика
- AI-обоснования отклонений
- Уведомления в Telegram при значительных изменениях

### Функции (ai-competitor-watchdog)
- Мониторинг сайтов конкурентов 24/7
- Распознавание цен на динамических страницах
- Уведомление при изменении цены или достижении порога
- Аналитика с историей изменений
- Pro-план: до 50 товаров за $9.99/мес

### Пример уведомлений
```
[price-monitoring]
Треска б/г: Иванов 185₽, Петров 178₽, Сидоров 192₽
✅ Рекомендуется: Петров (−7₽/кг от средней)

[Утренняя сводка]
📊 Доброе утро! Изменения за ночь:
• Минтай вырос на 12% у Петрова: 95₽ → 106₽
• Горбуша без изменений
Обновить свой прайс? [Да] [Пропустить]

[ai-competitor-watchdog]
⚠️ Конкурент снизил цену на минтай б/г:
было 185₽ → стало 170₽
Ваша цена: 178₽. Рекомендация: пересмотреть.
```

### Почему работает
- Fuzzy matching критичен для рыбной торговли: одна позиция имеет 10+ вариантов написания
- Владелец видит «где купить дешевле» без обзвона поставщиков
- Утренняя сводка заменяет 1–2 часа ручного мониторинга

### Ограничения
- Требует разработчика для установки и настройки
- Нет парсинга прайсов из текстовых сообщений Telegram-групп автоматически (это кастомная разработка)
- ai-competitor-watchdog работает с веб-страницами, нужна адаптация для PDF/Excel

### Что взять для нашего бота
- **Fuzzy matching** наименований — абсолютно необходим для рыбы
- Рекомендация «где купить дешевле» по каждой позиции — приоритет 1
- Алерт при росте цены → сигнал обновить собственный прайс
- Утренняя автоматическая сводка: «Вот что изменилось за ночь»
- История цен по позиции (тренд роста/падения)

## Пример 6 — SaleBot: мультиканальная рассылка прайса

**Платформа:** Telegram, WhatsApp, VK, Одноклассники, Email, Viber  
**Страна:** Россия (SaaS)  
**Источник:** [salebot.pro](https://salebot.pro)

### Задача
Мультиканальная платформа для создания чат-ботов, автоматических воронок продаж и массовых рассылок. Единая база подписчиков по всем каналам. **Единственный найденный инструмент**, покрывающий рассылку прайса одновременно по Telegram, WhatsApp и email.

### Функции
- Визуальный конструктор ботов (no-code)
- Массовые рассылки по всем каналам из одного интерфейса
- Автоматические воронки (цепочки сообщений по условиям)
- Единая база подписчиков: Telegram + WhatsApp + VK + ОК
- Сегментация базы для рассылок (разные условия — разным клиентам)
- Загрузка базы номеров WhatsApp
- Шаблоны с переменными (имя клиента, дата, цены)
- Расписание рассылок
- 60+ интеграций

### Пример рабочего процесса
```
Владелец загружает новый прайс-файл → нажимает «Рассылка»
Выбирает сегмент: «Все активные клиенты»
Настраивает сообщение: «Новый прайс на эту неделю [файл].
По вопросам — пишите сюда.»

SaleBot отправляет одновременно:
✅ Telegram-подписчикам бота
✅ WhatsApp-контактам
✅ Email-базе

Статистика: доставлено / открыто / кликнуло
```

### Почему работает
- Решает задачу №2 из idea.md — ежедневная рассылка прайса по всем каналам из одного места
- Персонализация: каждый получает письмо как личное («Добрый день, Александр!»)
- Сегментация: разные прайсы для разных типов клиентов

### Ограничения
- **Работает ТОЛЬКО с теми, кто уже написал боту (подписчики).** Холодная рассылка по купленным базам = риск бана аккаунта
- WhatsApp Business API — дополнительная оплата через провайдера
- Нет встроенного мониторинга цен поставщиков
- Нет AI-генерации контента

### Что взять для нашего бота
- Принцип «один прайс → рассылка по всем каналам»
- Сегментация базы: разные условия для ресторанов / магазинов / оптовиков
- Еженедельная персонализированная рассылка прайса подписчикам бота
- Акционные предложения с ограниченным сроком

## Пример 7 — SMMplanner + AI: автопостинг для торговли

**Платформа:** ВКонтакте, Telegram-канал, Одноклассники, TikTok и др.  
**Страна:** Россия (SaaS)  
**Источник:** [smmplanner.com](https://smmplanner.com)

### Задача
Планирование и автоматическая публикация постов в социальных сетях по расписанию. С 2024–2025 добавлены AI-ассистенты для генерации текстов и контент-планов.

### Функции
- Визуальный контент-план (календарь публикаций)
- Публикация в 11+ соцсетей из одного интерфейса
- Поддержка Telegram-каналов через токен от BotFather
- **AI-ассистент для генерации текста постов**
- AI-генерация контент-плана на неделю/месяц
- Шаблоны дизайна постов
- Работает через официальные API (нет риска блокировки)
- Тарифы: от 660 ₽/мес

### Пример рабочего процесса
```
Владелец вводит данные в AI-ассистент:
«Лосось, 250 ₽/кг, свежемороженый, Дальний Восток, акция этой недели»

SMMplanner AI генерирует текст поста с ценой,
описанием и призывом к действию

Владелец выбирает картинку, редактирует текст,
ставит время публикации

Пост автоматически публикуется:
✅ Telegram-канал
✅ ВКонтакте
✅ Одноклассники
```

### Почему работает
- Решает задачу №4 из idea.md (публикация в соцсетях) без ручного открытия каждой платформы
- AI-ассистент снижает время написания поста с 20–30 минут до нескольких минут
- Брендовый стиль без дизайнера — шаблоны оформления
- Официальные API: аккаунты не блокируются

### Ограничения
- Не умеет собирать прайсы поставщиков
- Не интегрируется с Telegram-ботом напрямую (это отдельный инструмент)
- Нет рассылки по WhatsApp/email

### Что взять для нашего бота
- Публикация одновременно в Telegram-канал, ВКонтакте, Одноклассники — прямое решение задачи №4
- AI-генерация текста с ценами и описанием: владелец диктует данные, AI пишет пост
- Расписание: владелец настраивает один раз утром, посты идут в течение дня
- Интеграция с ботом: при обновлении прайса → автоматически генерировать и публиковать пост

## Критический разрыв рынка

**Не существует** готового решения для:
1. Парсинга прайсов из **текстовых сообщений Telegram-групп** поставщиков в реальном времени
2. **Автоматического fuzzy-матчинга** названий рыбы от разных поставщиков в единую таблицу
3. **Всё в одном**: мониторинг цен + рассылка + PDF + контент из единого Telegram-бота

Это означает: **ниша открыта**, а бот для рыбного оптовика — первый комплексный продукт в России для этого сегмента.

## Универсальный коннектор источников (добавлено 12.11.2026)

**Концепция:** владелец вставляет любую ссылку в бота → агент сам определяет тип источника, извлекает цены через LLM и добавляет в мониторинг. Новый поставщик подключается за 10 секунд без разработчика.

### Технический стек по типу источника

| Тип | Инструмент | Сложность |
|---|---|---|
| Произвольный сайт | httpx + BeautifulSoup + LLM-экстракция | ✅ Просто |
| Telegram-канал/группа | Telethon (User API) | ⚠️ Нужен аккаунт |
| ВКонтакте | VK API (открытые группы) | ✅ Просто |
| PDF/Excel по прямой ссылке | Скачать + pdfplumber / openpyxl | ⚠️ Средне |
| Любой другой сайт | LLM читает HTML → ищет паттерны цен | ✅ Просто |

### Алгоритм (добавление источника)
```
1. Пользователь вставляет URL в бота
2. Агент определяет тип (сайт / Telegram / VK / файл)
3. Скачивает контент → отправляет в LLM с промптом:
   «Найди все позиции с ценами. Формат: название | цена | ед.изм.»
4. Показывает результат пользователю для подтверждения
5. Пользователь: ✅ → источник сохраняется в БД, добавляется в расписание мониторинга
6. При следующем обходе: сравнивает с предыдущими данными → алертит при изменениях
```

### Ключевое преимущество
Рынок живой — появляются новые поставщики, каналы, сайты. Эта фича даёт **независимость от разработчика**: владелец сам расширяет список источников в любой момент.

## Парсинг 2ГИС: сбор клиентской базы по Владивостоку

**Задача:** собрать базу потенциальных покупателей рыбопродукции — рестораны, коптильни, переработчики, магазины — из 2ГИС по Владивостоку.

### Целевые категории

| Категория | Тип клиента | Приоритет |
|---|---|---|
| Рестораны, суши-бары, кафе | HoReCa | 🔴 Высокий |
| Коптильни, рыбоперерабатывающие цеха | Переработчики | 🔴 Высокий |
| Рыбные магазины, отделы в супермаркетах | Ретейл | 🟡 Средний |
| Столовые, корпоративное питание | HoReCa | 🟡 Средний |
| Пивные, снэк-производства | Переработчики | 🟡 Средний |
| Гостиницы, санатории | HoReCa | 🟢 Низкий |

### Технические варианты парсинга

| Метод | Сложность | Риск | Результат |
|---|---|---|---|
| Playwright / Selenium (браузерная автоматизация) | ⚠️ Средне | Возможен бан IP | Полные данные |
| Готовые 2gis-parser (GitHub) | ✅ Просто | Нет гарантии актуальности | Телефон, адрес, категория |
| 2ГИС Deals API (официально) | ✅ Просто | Только часть данных | Ограниченный набор полей |
| Ручной экспорт из веб-версии | ✅ Просто | Нет | Медленно, но надёжно |

**Рекомендация для MVP:** готовый 2gis-parser на Python (open-source, есть на GitHub) — запускается один раз, собирает базу по нужным категориям, экспортирует в Excel/CSV.

### Что собираем
- Название организации
- Адрес (район Владивостока)
- Телефон
- Категория бизнеса
- Ссылка на профиль 2ГИС

### Как используется в боте
```
1. Парсер собирает базу → Excel/CSV
2. Владелец загружает файл в бота командой /import_clients
3. Бот сохраняет в базу данных (PostgreSQL)
4. Команда /broadcast → отправить КП по новой базе
5. Команда /call_list → выдать список с телефонами для обзвона
```

### Объём базы (оценка)
По Владивостоку в 2ГИС: ~800–1200 объектов общепита, ~50–100 переработчиков/коптилен, ~200–300 продуктовых магазинов. **Итого: ~1000–1500 потенциальных клиентов одним запуском парсера.**

## Рекомендации для технической спецификации

### Архитектурные решения
- **Стек:** Python + aiogram 3 + PostgreSQL + Redis (FSM) + n8n (оркестрация workflow)
- **CMS для прайса:** Google Sheets → прайс обновляется там, бот тянет автоматически
- **PDF-генерация:** WeasyPrint или ReportLab (open-source), шаблон разрабатывается один раз
- **Fuzzy matching:** библиотека `thefuzz` (RapidFuzz) для сопоставления наименований рыбы
- **Соцсети:** SMMplanner API или прямые API ВК + Telegram Bot API для публикаций

### Приоритет разработки (MVP → V2 → V3)
**MVP (1–2 месяца):**
1. Telegram-бот с командами: `/preis`, `/kp`, `/update_price`
2. Генерация PDF-прайса из Google Sheets
3. Рассылка прайса базе подписчиков бота
4. Уведомление клиентов при обновлении прайса

**V2 (3–4 месяца):**
5. Парсинг прайсов поставщиков из PDF/Excel файлов
6. Fuzzy matching наименований в единую таблицу
7. Рекомендация «где дешевле» по запросу
8. Утренняя сводка: «Вот что изменилось за ночь»

**V3 (5–6 месяцев):**
9. Автогенерация постов для Telegram-канала, ВК, ОК
10. Публикация по расписанию через SMMplanner API
11. Парсинг цен из Telegram-групп поставщиков (мониторинг в реальном времени)
12. Интеграция с 1С/amoCRM

### Риск: массовая рассылка в холодные группы
Прямая рассылка в Telegram-группы и WhatsApp-группы без согласия = **высокий риск бана аккаунта**. SaleBot работает только с теми, кто уже написал боту. Решение для холодных рассылок: отдельный аккаунт, ручная отправка с автоформированием сообщения.
