## Шаг 1 — suppliers.csv (поставщики)

**Где создать:** любой Excel или Google Таблицы → сохранить как CSV.

**Что заполнить:**

| name | telegram | phone | region | notes |
|------|----------|-------|--------|-------|
| Иванов А.П. | @ivanov_fish | +79241234567 | Сахалин | |
| Петров Снабжение | @petrov_opt | +79251234567 | Камчатка | Снижает цены по пятницам |
| ООО РыбаДВ | | +74232345678 | Владивосток | |

**Колонки:**
- `name` — имя или название компании
- `telegram` — @username (если есть), иначе пусто
- `phone` — номер телефона
- `region` — Сахалин / Камчатка / Владивосток / Хабаровск и т.д.
- `notes` — любые заметки: условия, особенности, когда лучше звонить

**Сколько строк:** все поставщики, с кем работаешь или работал. Минимум 5, лучше всех.

**Сохранить как:** `suppliers.csv` (кодировка UTF-8)

| name | type | telegram | phone | email | city | min_order_kg | discount_pct | notes |

| Ресторан Море | ресторан | @more_rest | +74951234567 | more@mail.ru | Москва | 20 | 5 | |

| ИП Козлов | оптовик | @kozlov77 | +79161234567 | | Москва | 500 | 15 | Берёт только красную рыбу |

**Колонки:**
- `name` — название организации или имя
- `type` — одно из: `ресторан`, `магазин`, `оптовик`, `физлицо`, `коптильня`, `переработчик`
- `telegram` — @username (если есть)
- `phone` — телефон
- `email` — email (если есть)
- `city` — город
- `min_order_kg` — минимальный заказ в кг (можно пусто)
- `discount_pct` — скидка в % от твоего прайса (0 если нет скидки)
- `notes` — что берёт, особые условия, история

**Сколько строк:** все активные клиенты. Если база большая — начни с самых активных 20–30, остальных добавим позже через бота.

**Сохранить как:** `clients.csv` (кодировка UTF-8)

## Шаг 3 — products.csv (позиции прайса)

| name | category | aliases | unit | season_note |
|------|----------|---------|------|-------------|
| треска б/г | белая рыба | треска без головы, ТРЕСКА БГ, треска дв бг | кг | |
| лосось с/м | красная рыба | лосось свежемороженный, сёмга с/м | кг | |
| горбуша с/м | красная рыба | горбуша | кг | июль–сентябрь |
| минтай б/г | белая рыба | минтай без головы, МИНТАЙ БГ | кг | |
| креветка 90/120 | морепродукты | креветка варёно-мороженая 90/120 | кг | |
| икра горбуши | икра | икра г/б, икра лососёвая | кг | |

**Колонки:**
- `name` — **каноническое** (главное) название: именно так будет в прайсе
- `category` — одно из: `белая рыба`, `красная рыба`, `морепродукты`, `икра`, `пресервы`
- `aliases` — все варианты написания через запятую (нужно для распознавания от поставщиков)
- `unit` — единица: `кг` (почти всегда), `шт` для икры в банках
- `season_note` — если сезонная: когда ловят / когда цена меняется

**Сколько строк:** все позиции из твоего текущего прайса. Это самый важный файл — чем больше псевдонимов (`aliases`), тем лучше бот распознаёт цены от поставщиков.

**Сохранить как:** `products.csv` (кодировка UTF-8)

## Шаг 5 — Данные для .env

Собери следующее в одном месте (заметка в телефоне, текстовый файл):

```
Название компании / ИП:    ИП Иванов Алексей Петрович
Телефон для прайса:        +7 924 XXX-XX-XX
Telegram для прайса:       @aleksey_fish
WhatsApp для прайса:       +7 924 XXX-XX-XX  (если отличается)

Условия поставки (1–3 строки, как пишешь клиентам):
  Минимальный заказ 50 кг.
  Доставка по договорённости или самовывоз.
  Оплата наличными или безналичным расчётом.

Email для рассылок:        твой@mail.ru
Пароль приложения email:   (создать отдельно — см. ниже)
```

**Пароль приложения для Mail.ru:**
1. Зайди на mail.ru → Настройки → Безопасность
2. Раздел «Пароли для внешних приложений»
3. Создай новый → скопируй пароль → вставь в список выше
